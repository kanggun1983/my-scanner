🔐 종단간 암호화 (문자 내용·번호를 SMSGate 서버가 못 보게)

[연결 확인]을 누르면 켜져 있는지 보여요.

  1. SMSGate 앱 → SETTINGS → Encryption → Passphrase에 붙여넣고 저장
  2. Cloudflare → kangcrm-push → 설정 → 변수 및 비밀 → 추가 → 유형 '비밀' → 이름 SMSGATE_E2E_KEY → 값 붙여넣기 → 배포
  3. 위 [연결 확인] → "🔐 암호화 켜짐" 확인 → [테스트 문자 보내기]

이 암호문은 어디에도 저장되지 않아요. 두 곳에 똑같이 넣기 전에 창을 닫았으면 새로 만들어주세요. 두 값이 다르면 매장 폰에서 문자를 못 풀어서 실패해요. 캡처해서 다른 곳에 올리지 마세요.
